# love-at-furst-sight

Love at Furst Sight — dog boarding & daycare homepage mockup, built in the Soft
Brutalist Editorial design language (cream surfaces, sage and terracotta accents,
light-weight Manrope at tight tracking, generous radii).

## Contents
- `index.html` — fully self-contained standalone build (photography, Manrope and
  all scripting inlined). Open directly in any browser; works offline. Vanilla
  JS, no framework and no build step.

## Sections
Pill nav with a section indicator and mobile menu · full-bleed photo hero ·
word-scrub statement · before/after comparison cards · four sticky service
panels · measured-results band · testimonials · booking form · footer.

## Branches
- `main` — the live direction, Soft Brutalist Editorial.
- `soft-brutalist` — the design branch `main` is merged from.
- `editorial-venture` — Editorial Venture: deep forest green, Fraunces at
  display size, a pinned programme index whose cards swipe in from the right.
- `creamy-gradients` — the earlier Dit Is Watt direction (butter-cream surfaces,
  indigo ink, DM Sans / Inter Tight, gradient blobs), kept as a standing copy.
  This one is a compiled React + GSAP bundle rather than hand-written source.
